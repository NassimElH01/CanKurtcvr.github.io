# Nassim Hassani | CV & Profile Website

A polished personal CV/profile website built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
